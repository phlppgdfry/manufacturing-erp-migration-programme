# Begrippen

> De vaktermen uit deze case, kort uitgelegd.

| Term | Betekenis |
|---|---|
| **Afstemming** (reconciliation) | Vergelijken van totalen in het oude en het nieuwe systeem na een migratie: voorraadwaarde, openstaande posten, grootboeksaldi. Elk verschil heeft een verklaring of het is een fout. |
| **Artikeltracering** (item tracking) | Functie in Business Central om lot- of serienummers te registreren bij elke boeking, zodat een lot voorwaarts en achterwaarts te volgen is. |
| **Business Central Premium** | Licentie van Microsoft Dynamics 365 Business Central die onder meer productie (productiestuklijsten, routings, productieorders) bevat. Essentials en Premium kunnen niet gemengd worden. |
| **Change request (CR)** | Formeel verzoek om de scope te wijzigen, met impactanalyse en een beslisser. |
| **Configuratiepakket** | Middel in Business Central om gegevens en instellingen in bulk in te laden, onder meer bij migraties. |
| **CRP** (conference room pilot) | Sessie waarin key users het ingerichte proces doorlopen met eigen gegevens, vóór de formele tests. |
| **Cutover** | De periode en het draaiboek waarin het oude systeem stopt en het nieuwe start. |
| **DESADV** | EDI-leverbericht (EDIFACT) dat aankondigt wat er geleverd wordt, vaak met SSCC per pallet. |
| **Extensie** | Eigen code (AL) bovenop Business Central. Moet bij elke update getest worden. |
| **FEFO** | First expired, first out: eerst picken wat het eerst vervalt. |
| **Fit-gap** | Per eis vastleggen hoe het pakket het oplost: standaard, configuratie, app, procesaanpassing of extensie. |
| **Go/no-go** | De beslissing om live te gaan, op basis van vooraf vastgelegde criteria. |
| **Hypercare** | De eerste weken na de go-live met extra ondersteuning. |
| **Hard / zacht criterium** | Een hard criterium moet slagen voor een go; zachte criteria mogen beperkt falen met een workaround. |
| **ISV-app** | App van een onafhankelijke softwareleverancier, via AppSource. |
| **Key user** | Medewerker die mee ontwerpt, test en collega's opleidt. |
| **Lot / batch** | Hoeveelheid die onder dezelfde omstandigheden geproduceerd of ontvangen is, met één nummer. |
| **MCH1 / MCHB / CHVW** | SAP-tabellen voor batches: stamgegevens (o.a. vervaldatum), voorraad per batch, en het batchgebruik (genealogie). |
| **Minimale resterende houdbaarheid** | De houdbaarheid die een product minstens nog moet hebben bij levering, vaak een contractuele eis van retailers. |
| **Mock recall** | Oefening waarin een lot voorwaarts en achterwaarts getraceerd wordt, alsof het een echte recall is. |
| **MoSCoW** | Prioriteren in Must, Should, Could, Won't. |
| **Peppol** | Netwerk voor gestructureerde e-facturen; in België verplicht voor B2B-facturen sinds 1 januari 2026. |
| **Planningsvoorstel** | Business Central-functie die uit vraag en voorraad productie- en aankoopvoorstellen berekent (MRP). |
| **Proefmigratie** (mock migration) | Volledige testmigratie met echte (hier: gegenereerde) data, om het draaiboek, de kwaliteit en de afstemming te testen. |
| **RAID** | Log van risico's, aannames, issues en afhankelijkheden. |
| **RACI** | Wie Responsible, Accountable, Consulted en Informed is per activiteit. |
| **Reserve** (contingency) | Deel van het budget voor onvoorziene kosten, met een beslisregel voor gebruik. |
| **SIT** | Integratietest tussen systemen. |
| **SSCC** | Serial Shipping Container Code: uniek nummer per pallet (GS1). |
| **Stuurgroep** | Het orgaan dat beslist over budget, scope en go-live. |
| **UAT** | Gebruikersacceptatietest: key users testen of ze hun werk kunnen doen. |
| **Z-object** | Eigen ontwikkeling in SAP (programma, tabel, transactie), naar de naamconventie met Z of Y. |
